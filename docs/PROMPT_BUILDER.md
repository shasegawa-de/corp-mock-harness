# Prompt Builder — vNext

> **注：この文書には2026-10-20時点の初期設計（画像拡大・右フィルターモーダル・240msなど）が履歴として含まれます。** 2026-10-21までのレビューで確定した現行のUI判断・却下理由は [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md) を優先し、実動作は main の `catalog-next/` と自動テストで確認してください。プロンプト組立のアルゴリズムと画像QA・生成正本の区別は引き続き有効です。

## 決定と公開場所

- 2026-10-20：現行カタログは現状で保持し、次期版で条件の掛け合わせにプロンプトを連動させる。
- 現行：https://shasegawa-de.github.io/corp-mock-harness/ （正本：`catalog/index.html`、内容変更なし）。
- 次期：https://shasegawa-de.github.io/corp-mock-harness/next/ （ソース：`catalog-next/`）。
- 画像生成・外部AIへの送信は行わない。条件から単一シーンの英文をブラウザ内で組み立てる。
- UI文言は操作名・条件・検証状態に必要なものだけにする。依頼のないキャッチコピー、装飾的な英語見出し、重複説明は追加しない（ユーザー指示、2026-10-20）。
- 全バージョンのトーン＆マナーを現行カタログから変えない。配色、書体、カード、画像、一覧、拡大は正本を共用する。次期版のヘッダーは指定された肩書き・タイトル・GitHubリンクの3要素のみ。項目名は「対象・配置・素材・評価」。既存の対象・配置・素材・評価の排他タグをすべて保持し、絞り込みボタンから独立した右ハーフモーダルで操作する。項目間はANDで絞り込み、件数とクリア操作を維持する。背景クリック・Escape・閉じる／結果を表示で閉じ、フォーカスは呼び出し元へ戻す。小画面は全幅表示し、動きを抑える設定を尊重する。
- 作例・一覧表の「プロンプト確認」からサイドモーダルを開く。カード内の「プロンプト全文」開閉表示を廃止し、モーダル初期表示は元の完成プロンプト全文とコピー・GitHub参照とする。条件を編集した場合のみ「条件変更後のプロンプト（未検証）」へ切り替える。編集UIをカード内に置かず、閉じると元の表示・操作位置へ戻る。既存のギャラリーと一覧表は残す。
- モーダルの出力例は対象・並び方・配置・姿勢・建築面・構図・素材・照明の8条件が一致する既存作例のみ。条件変更ごとに更新し、一致がなければ空状態を表示する。元の画像QAを併記し、組立プロンプトとの厳密な一致は未検証と明記する。
- TXT保存、プロンプト内訳、選択条件JSONのUIは削除。出力操作は全文コピーのみ。
- カテゴリ別のギャラリーセクション・下位グループを次期版の生成HTMLから除去し、全カードを1つのグリッドにフラット化する。カテゴリはカードの data-device 属性として保持し、対象・配置・素材・評価のAND絞り込みを維持。元の表示順、30件の画像とプロンプト・QA、一覧表を維持し、既存の catalog/index.html は変更しない。カタログ上部の案内文はページ末尾のフッターに移動し、廃止済みの検索機能の記述は除去。ヘッダー上下余白を縮小。これらはvNextだけで適用する。

**却下した構成：** 作例・一覧をなくした独立フォームと別の緑系デザイン。比較・参照の体験とデザインの継続性を壊すため。これを再導入しない。

## 条件と依存関係

対象（iPhone / Mac / 2台 / 環境のみ）、2台の並び方、姿勢、配置、構図、建築面、素材、照明を扱う。選択肢のIDは既存の`configs/`を参照する。

- 端末0台では筐体・姿勢・白画面の肯定指示を除く。空間／壁／壁床接合／壁角／ガラス壁床／床面主体を分ける。
- iPhone単体の寝かせ姿勢では床・台に応じた斜め上カメラに固定。傾斜には物理的な支持を入れる。
- Macは常に開く。2台ではMacとiPhoneを各1台、相対スケールと画面・キーボードの可視性を維持。
- suspendedでは素材名に「wall-floor」が含まれていても、描く空間は縦壁のみへ変換し、床・水平線・床影・支持物を除外。hoverと混同しない。
- 建築面のガラス／壁／床を指定すると素材もスモークガラスに連動。on-blockで「自立ブロックなし」を指定する背景は候補から除く。
- 無効な組み合わせは依存する選択肢を調整し、変更内容を表示。廃止したhigh-viewは選択不可。

## プロンプトの組立

`engine.mjs`の短い英文句は、現行AGENTS/STYLEと各設定の制約を踏まえた新規の組立用記述。既存プロンプト全文の単純連結ではない。筐体寸法は`devices.json`から直接読む。構図・素材・照明等のIDに対応する句を結合し、80〜170語の単独画像プロンプトを出す。

各作例の「プロンプト確認」は**元プロンプトの表示と条件の読込**。完成プロンプトそのものの復元ではなく、元のプロンプト全文・コピー・GitHubリンクも従来どおり残す。作例の採用状態を新しい組立文へ付与しない。

設定追加・変更時は対応する英文句と依存ルールもレビューする。未対応IDや欠けた既知の配置・姿勢を検出した場合は読込を止める。英文句を自動的に翻訳・解釈するAIは組み込まない。

## 公開・検証

`node scripts/build-pages.mjs`で`_site/`を作成。現行の`catalog/`をルートへそのままコピーする。次期版も同じ`catalog/index.html`から`render-next-catalog.mjs`で構成し、30件の画像・カード・一覧表・共有スタイル・既存スクリプトを保持する。指定されたヘッダーと絞り込みの構造だけを変換し、サイドモーダルと追加ファイル参照を挿入する。追加CSSは変更箇所に限定する。必須4ファイルを`next/data/`へ配置する。GitHub Pagesワークフローは設定・ハーネス・次期版の変更でも再公開する。正本の重複管理はしない。

`node --test tests/prompt-builder.test.mjs`で、正本・画像・カード・一覧表・共有スタイルの保持、指定ヘッダーと絞り込み構造、8条件すべての完全一致判定、30件の作例と編集条件の対応、具体的な矛盾ケース、全選択可能組み合わせの語数・端末数・床なし条件を検査。これは**ソースとテキスト・状態遷移の検証**であり、画像の品質・筐体再現・実効プロンプト一致の証明ではない。

## 未確認・継続事項

- 組立文を使った実画像生成・人間レビューは未実施。画像QAとプロンプト監査は従来の必須4ファイル契約に従う。
- 出力例は既存作例の条件メタデータとの一致を表す。変更後の組立プロンプトを実行した結果ではない。新しい生成結果・検証済み画像として扱わない。
- 自由文の追加、複数シーンの一括出力、生成API連携は今回の対象外。
- 操作アニメーション：サイドモーダルは240msのスライドと背景フェード、絞り込みタグは160msの状態遷移、カードは220msの表示アニメーション。`prefers-reduced-motion`では無効化する。画像生成やQAの承認とは別。


## タグ絞り込みの詳細条件（2026-10-21）

vNextの右側フィルタードロワーを、プロンプト確認モーダルと対応する **8条件（対象・並び方・配置・姿勢・建築面・構図・素材・照明）と、従来の評価** の計9項目に拡張する。タグのID・名称は `catalog-next/engine.mjs` と `configs/presets.json` に従い、独自のラベル一覧を持たない。各項目に「すべて」を設け、同時選択した条件を既存30作例の正確なメタデータに対してANDで判定する。条件が未生成の場合は0件とし、既存プレビューを新規の出力に偽装しない。

評価フィルターは現行カタログの処理に委ね、元のフィルター制御・ライトボックス・一覧表示機能をDOMに保持する。vNextの追加条件はギャラリーのカードと一覧テーブルに共通適用する。条件編集モーダルは変更せず、`catalog/index.html`も保持する。ブラウザテストで全9項目、0件、クリア、モバイル操作、プロンプト起動を確認する。
